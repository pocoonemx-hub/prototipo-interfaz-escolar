# Prototipo de Interfaz Escolar (CECyTE Mobile)

## Descripción del Proyecto
Proyecto enfocado en el diseño de una interfaz centrada en el usuario para la gestión de tareas y horarios escolares en dispositivos móviles.

## Integrantes del Equipo
* Tu Nombre Completo

## Objetivos Generales
* Diseñar una interfaz limpia, accesible e intuitiva para estudiantes.
* Facilitar el seguimiento de tareas pendientes y horarios de clases.
* Implementar metodologías ágiles utilizando Trello y GitHub para el control del proyecto.
